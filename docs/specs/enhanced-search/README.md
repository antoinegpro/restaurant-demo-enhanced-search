# Epic: Enhanced Menu Search

Lets diners find dishes on the menu page by keyword, category, dietary need, and price, and sort results, instead of scrolling a flat list.

**Persona:** Diner — a customer browsing the public menu page (desktop or mobile) before adding items to cart. No internal/ops persona is affected; this app has no back-office/admin interface today.

## Specs

1. [Free-text search by name/description](01-free-text-search.md)
2. [Multi-select category filter](02-category-multiselect.md)
3. [Dietary tags filter (vegetarian/vegan/gluten-free)](03-dietary-tags-filter.md)
4. [Price range slider](04-price-range-filter.md)
5. [Sort by price/popularity](05-sort-results.md)
6. ["No results" empty state](06-no-results-state.md)
